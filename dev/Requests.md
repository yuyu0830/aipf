# 새 개선 요청

불편한 점과 원하는 결과를 자유롭게 적는다. 대상은 `Dev` 또는 `AIPF`로 구분하고, 헷갈리면 적용 전에 사용자에게 묻는다. 필요한 경우 R001처럼 번호를 붙인다.

논의 후 적용 범위를 정하고, 사용자가 실행을 지시하면 [Status.md](Status.md)로 옮긴다. 완료한 기록은 여기에 쌓지 않는다.

현재 대기 중인 새 요청은 없다.

작성 예시:

```markdown
## R001 — 요청 제목
- 대상: AIPF
- 불편한 점:
- 원하는 결과:
- 합의한 적용 범위: 논의 후 작성
```
