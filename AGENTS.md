# Agent Instructions

## Repository layout

- `dev/` contains AIPF source code, tests, packaging, and product direction.
- `example/` contains inspectable output generated by `aipf init`.

## Required startup context

Read `dev/PROJECT_DIRECTION.md` before framework work. Inspect only source and tests relevant to the current request.

## Operating rules

- Apply framework changes to `dev/` first.
- Run relevant tests in `dev/` before updating `example/`.
- Update `example/` only when a verified change affects `aipf init` output.
- Regenerate `example/` through the CLI. Do not treat it as implementation source.
- Never store secrets in project files. Use environment variables for Telegram credentials.

## Scope control

Do not add orchestration, multi-agent review, model routing, persistent sessions, automatic planning, or concurrency systems unless the user requests them.
